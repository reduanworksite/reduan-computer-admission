সচরাচর জিজ্ঞাসা

ভর্তি, পেমেন্ট ও Student ID সম্পর্কে সাধারণ প্রশ্নের উত্তর।

ভর্তি আবেদন করতে কী কী লাগবে?

আপনার পূর্ণ নাম, মোবাইল নম্বর, ঠিকানা, পছন্দের ব্যাচ, পেমেন্টের তথ্য (যে নম্বর থেকে টাকা পাঠিয়েছেন, Transaction ID, পরিমাণ, তারিখ) এবং পেমেন্ট রসিদের স্ক্রিনশট। WhatsApp নম্বর ও ইমেইল ঐচ্ছিক।

পেমেন্ট কীভাবে করবো?

bKash অথবা Nagad-এ Send Money করুন। পেমেন্ট নম্বর জানতে কল করুন 01410645030। পেমেন্টের পর Transaction ID (TrxID) ও রসিদের স্ক্রিনশট ফরমে জমা দিন।

Student ID কখন পাবো?

আবেদন সফলভাবে জমা হলেই সঙ্গে সঙ্গে আপনার Unique Student ID (RC-2026-XXXX ফরম্যাটে) স্ক্রিনে দেখানো হবে। ID-টি অবশ্যই সংরক্ষণ করে রাখুন।

Student ID কেন সংরক্ষণ করবো?

অনলাইন ক্লাস Google Meet-এর মাধ্যমে হয়। ক্লাসে Join করার সময় এবং আপনার শিক্ষার্থী পরিচয় যাচাইয়ের জন্য এই Student ID প্রয়োজন হবে।

পেমেন্ট যাচাই হতে কত সময় লাগে?

আবেদনের পর আপনার পেমেন্টের অবস্থা প্রথমে “Pending” থাকে। কর্তৃপক্ষ Transaction ID ও রসিদ যাচাই করে আবেদনের অবস্থা আপডেট করবেন। কোনো সমস্যা হলে আপনার মোবাইল নম্বরে যোগাযোগ করা হবে।

একই Transaction ID দিয়ে দুবার আবেদন করা যাবে কি?

না। একই Transaction ID দিয়ে দ্বিতীয় আবেদন স্বয়ংক্রিয়ভাবে শনাক্ত করা হয় এবং গ্রহণ করা হয় না। ভুলবশত জমা হয়ে গেলে 01410645030 নম্বরে যোগাযোগ করুন।
